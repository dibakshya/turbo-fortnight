Ishana - InfoSec Tools Dashboard (Static SPA MVP)

Run locally:

```bash
cd /workspace/ishana
python3 -m http.server 8080
# then open http://localhost:8080
```

Or with Node (if available):

```bash
npx --yes serve -l 8080 /workspace/ishana
```

Structure:

- index.html
- styles.css
- main.js
- mock-data/tools.json, mock-data/metrics.json
